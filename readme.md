# Python CLI To-Do List

A lightweight Command-Line Interface (CLI) task manager built with Python. It reads from and writes to a local text file (`todo.txt`) to maintain persistent task states across sessions.

---

## Features & Highlights

* **Persistent File Storage:** Reads, creates, and deletes task entries in a local `todo.txt` file.
* **Core Task Operations:**
  * **Create:** Add new tasks directly to the list.
  * **Read:** Display all pending tasks in order.
  * **Delete:** Remove completed or unwanted tasks from the text file.
* **Zero Dependencies:** Built entirely using Python's standard library.
